# UMA — Serie infantil original (guiones + producción con Higgsfield)

Contenido para el canal de YouTube, inspirado en el **tono y calidad** de las series
infantiles familiares más vistas — con un mundo, especie y personajes **100% originales**,
para evitar cualquier reclamo o strike de copyright.

## Estructura

```
serie-uma/
├── 00-biblia-de-la-serie.md          # Mundo, personajes, guía de estilo — LEER PRIMERO
├── personajes/
│   └── referencias.md                # Prompts + vistas previas de Uma y Bibo (Higgsfield)
├── canal/
│   ├── identidad-canal.md            # Nombre del canal (Uma Coral) + foto de perfil + banner
│   └── guia-lanzamiento-canal.md     # Descripción, palabras clave, ajustes y consejos de crecimiento
└── episodio-01-el-reino-de-los-charcos/
    ├── guion-largo.md                # Episodio completo, ~7 min, formato guion
    ├── guion-corto-short.md          # Recorte <60s del mismo episodio, 9:16
    ├── plan-produccion-higgsfield.md # Respuestas de intake + desglose en bloques de 10s
    └── short-produccion.md           # Registro de producción del Short ya publicado
```

## Cómo seguimos

1. **Aprobar el diseño** de Uma y Bibo (`personajes/referencias.md`) — si algo no convence,
   se puede ajustar el prompt y regenerar antes de tocar el episodio.
2. **Elegir con qué arrancar la producción real en Higgsfield:** el Short (rápido y barato,
   sirve de piloto) o el episodio largo directamente. Ver la nota de alcance/costo en
   `episodio-01-el-reino-de-los-charcos/plan-produccion-higgsfield.md`.
3. Para cada episodio nuevo: se agrega una carpeta `episodio-NN-titulo/` con la misma
   estructura (guion largo + short + plan de producción), siempre revisando primero
   `00-biblia-de-la-serie.md` para que los personajes no cambien de un video a otro.
